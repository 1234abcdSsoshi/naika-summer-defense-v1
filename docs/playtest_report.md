# 内蚊 — 実プレイテスト記録

実際のブラウザ操作で通常プレイを開始し、蚊の表示、蚊のタップ入力、小判生成、寝息減少、ゲーム終了、結果画面、匿名イベント集計を確認した。蚊DOMの中心座標からキャンバスへ入力を発生させたところ、得点168、撃破1、命中率100%として結果画面へ反映された。

ブラウザコンソールには、描画・入力・音声に関するエラーは確認されなかった。プレイ中に小判回収とアイテム設置まで進めるには初期コイン4枚に対して購入価格が6枚以上であるため、今回の通常プレイでは経済上そこまで到達しなかった。これはバグではなく、初期報酬設計と確認手順上の制約として記録する。

## BGM音量調整後の再確認

開始ボタンを押した後、BGM要素は再生中（`paused: false`）で、`volume: 0.1`、再生位置14.88秒を確認した。タイトル画面だけでなく、開始後の実プレイ状態で音量設定が適用されている。モスキート音と操作効果音は別経路で再生されるため、BGMを下げた状態でも重なりを抑えられる構成である。
