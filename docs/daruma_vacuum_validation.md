# だるま巡回・小判吸引の確認記録

だるまは設置位置を起点に、畳の上を横約1.12・縦約0.86の範囲で緩やかに巡回する。DOM表示は同一キーを保ったまま座標だけを更新するため、移動中に再生成されず、軽い上下の弾みを伴って見える。

射程内の小判を検知すると、だるまを追跡する吸引目標を小判へ設定する。小判は更新ごとに移動中のだるまの現在座標を目標にして近づき、十分近い距離になると自動回収される。

確認用画面では、稼働中のだるまのDOM座標が2.5秒の間に変化することを確認し、巡回移動が継続することを検証した。小判単独確認では、だるま稼働中に小判残高が4から5へ増え、得点0のまま小判DOMが消えることを同一のDOM状態で確認した。Vitest 8件、型検査、本番ビルドも成功している。
