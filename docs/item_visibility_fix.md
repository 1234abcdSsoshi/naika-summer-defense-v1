# 内蚊 — 防衛アイテム表示の修正記録

防衛アイテムの実装は、Babylon上の設置物に加えてDOM表示レイヤーを持つよう変更した。ゲーム本体は、設置中のアイテム種別・座標を画面ホストへ通知し、画面側は畳の上に対応する木版画調のシルエットを表示する。これにより、テクスチャ読込や3Dレイヤーの都合に依存せず、アイテムを購入して設置した直後から可視化される。

| アイテム | 画面内の印象 | 可視効果 |
|---|---|---|
| 蚊取り線香 | 緑青色の渦巻きと煙 | 周囲の蚊を退ける範囲が分かる |
| 招き猫 | 白地に朱の招 | 蚊を引き寄せる目標が分かる |
| カエル | 緑の丸い顔と目 | 攻撃役として判別できる |
| ダルマ | 朱色に「守」の印 | 小判を回収する役割が分かる |

検証用画面で線香を自動配置し、畳上のアイテム、煙、名称、アイテムトレイの「稼働中」表示を確認した。型検査と本番ビルドも完了している。
