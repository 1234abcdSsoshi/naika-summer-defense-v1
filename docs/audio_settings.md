# 内蚊 — 個別音量スライダー

画面右端にBGMと効果音の縦型スライダーを追加した。BGMの初期値は前回調整値の0.10、効果音は1.00で、変更値は端末のlocalStorageへ保存する。BGMを実操作で変更し、DOMの値と保存値が同じ値へ更新されることを確認した。効果音変更はCustomEventでGameWorldへ通知され、モスキート音、音程効果、回収音、設置音にリアルタイムで反映される。

モバイル幅375pxで、スライダーが右端の独立した音量ドックとしてタイトル画面に表示され、ゲーム本体の操作エリアと重ならないことを確認した。型検査と本番ビルドも成功している。

## 最終操作確認

onInputへ変更後、効果音スライダーを実入力で0.35相当まで動かし、再描画後の実値0.5と`naika-sfx-volume: 0.5`の保存を確認した。BGMも`naika-bgm-volume: 0.5`として独立保存され、2本のスライダーが別々に操作できることを確認した。
