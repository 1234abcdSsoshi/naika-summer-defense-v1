# 招き猫の本体手振りアニメーション：確認記録

以前の独立肉球オーバーレイは撤去した。招き猫の手振りは、生成した4フレームの透明スプライトシートを本体アートへ重ね、既存アトラスを透明部分のフォールバックとして併用する方式に置き換えた。

各フレームでは、招き猫本体の前脚の高さと曲がり方が変化する。CSSの `cat-sprite-wave` は1.36秒で4フレームを切り替え、胴体から独立した前脚要素は追加しない。

設置確認画面で、独立肉球がなく、招き猫本体・射程表示・右下タイマーが同時に表示されることを確認した。生成画像が一時的に透明部分を返す場合にも、既存アトラスが本体シルエットを維持する。

ブラウザの実行時確認では、招き猫本体アートが存在し、`data-item-motion="sprite-waving"` と `cat-sprite-wave` が稼働していること、420msの間に背景位置が切り替わることを確認した。独立肉球の `cat-waving-paw` 要素は存在しない。

生成済みの1920×1920スプライトシートを直接確認した。2×2の4フレームすべてで同一の招き猫本体が描かれ、前脚は「やや下げる → 中間まで上げる → 高く上げる → 中間へ戻す」と段階的に変化している。ゲーム画面でも生成スプライトを本体として表示し、独立肉球を使わずに前脚位置が切り替わる構成を確認した。

セル個別確認では、フレーム1（`01_paw_low`）は肩より低い招き前脚、フレーム2（`02_paw_mid_up`）は肩より高い位置の招き前脚であることを確認した。顔・胴体・装飾の意匠は共通で、前脚位置だけが変化する。

フレーム3（`03_paw_high`）では前脚が頭より高く伸び、フレーム4（`04_paw_return`）では肩付近の位置へ戻ることを個別に確認した。4セルはいずれも同じ顔・胴体・首輪・提灯装飾を保ち、本体の右前脚のみが「低い → 中間 → 高い → 戻る」の順に一貫して動く。
