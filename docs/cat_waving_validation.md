# 招き猫の手振りアニメーション：確認記録

招き猫の設置確認画面（`?visual-check=1&item=cat&item-hold=1`）で、招き猫本体の右上から丸い肉球の前脚が自然に伸び、射程の点線と右下タイマーを遮らないことを確認した。

前脚は本体とは独立したDOM要素として描画し、腕の付け根を基点に往復する。身体側にはわずかな揺れを加え、前脚だけが不自然に浮いて見えないよう調整した。`prefers-reduced-motion` が有効な環境では、既存の全体規則によりアニメーションを抑制する。

ブラウザの実行時確認では、前脚要素が存在し、`data-item-motion="beckoning"`、前脚の `cat-waving-paw`、本体の `cat-body-bob` が稼働していることを確認した。420ms間隔で取得した前脚の変形値も変化しており、静止スタイルではなく動作中であることを確認した。
