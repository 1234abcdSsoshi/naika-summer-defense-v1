# 内蚊 — 3Dモーションと操作音

敵の飛翔は、目的地へ即座に向かうのではなく、目標速度へ追従する慣性を持つ移動へ変更した。横方向の速度は機体の傾きに反映され、上下の小さな浮遊、明滅、影の変化によって3Dデジタル風の飛行感を補強する。

カエルは捕食対象を見つけると、少し持ち上がって縮み、420msの間だけ発光する桃色の舌を対象方向へ伸ばす。敵の撃破と舌の演出は同じ捕食イベントから発生するため、対象と演出の位置がずれない。

小判を手動で回収すると、金属のチャリンと短い余韻が鳴る。防衛アイテムを畳に置くと、漆器の着地と陶器のクリックを感じる短い設置音が鳴る。両方の音は複製再生されるため、連続操作でも前の音を止めない。音声はブラウザの自動再生制約を考慮し、開始操作によって音声経路が有効化された後に再生される。
