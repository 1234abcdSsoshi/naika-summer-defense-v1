# 寝ている中年男性の状態演出 — 検証記録

通常体力の確認画面では、フィールド下部に青い布団で眠る中年男性が明確に表示された。`sleeper=bitten` では頬と腕に少数の赤い刺し跡が現れ、眉間がやや曇った寝顔へ切り替わった。`sleeper=distressed` では刺し跡が5個に増え、眉間を寄せた険しい表情へ切り替わった。

初回の `game-over-check` 画面確認は、エンジン起動とゲームオーバー遷移の時間差により寝姿の途中状態を取得した。このため確認URLでは初期描画から目覚めオーバーレイを表示するよう調整した。実プレイでは体力が0になると、短い目覚め演出の後に結果カードへ遷移する。

最終確認では、`sleeper=bitten` の寝息ゲージが62、`sleeper=distressed` の寝息ゲージが28と表示され、それぞれ対応する刺し跡数と表情へ同期していた。`game-over-check` では、男性が布団から起き上がり、刺された腕を押さえて驚く目覚め演出が実画面で表示された。

確認専用の見た目上書きではなく、ゲームワールドが配信する体力値を使った `health-check=62` と `health-check=28` でも、寝息ゲージ・刺し跡・表情が同じ閾値で連動した。さらに `game-over-result-check` では、目覚め演出を経過した後に「目を覚ましてしまった。」というゲームオーバー結果カードが表示された。これにより本番フローは「目覚め演出→結果カード」の順序であることを確認した。

さらに、通常の `bitePlayer` を直接通す `damage-demo` で確認した。1回の被弾後は寝息62、刺し跡2個、軽い眉間の曇りへ変化した。2回の被弾後は寝息24、刺し跡5個、険しい寝顔へ変化した。3回の被弾による体力0到達時は、目覚め演出を経由した後、寝息0・「蚊に起こされてしまった…」の通知とともにゲームオーバー結果カードへ遷移した。

最後に、直接被弾を呼び出さず、通常の蚊移動・到達判定・`feeding` 状態・吸血処理を経由する `mosquito-flow-demo` で確認した。蚊が寝息へ到達して吸血すると、初期寝息76から67へ下がり、刺し跡2個と軽い眉間の曇りが現れた。初期寝息40では31へ下がり、刺し跡5個と険しい表情に切り替わった。初期寝息8では蚊の吸血後に0へ到達し、実画面で男性が目を覚ます演出が先行することを確認した。目覚め演出の完了後は、前記の本番タイマーにより結果カードへ遷移する。

通常蚊の到達・吸血経路に限定した `mosquito-flow-result-demo` でも、寝息0を経て「目を覚ましてしまった。」の結果カードが実画面に表示された。したがって、通常の被弾経路での最終フローは「蚊が到達して吸血 → 寝息0 → 目覚め演出 → 結果カード」であることを確認した。

## 枕付き睡眠表示の確認（2026-08-15）

375×812のモバイル実画面で、上半身のみの中年男性の頭の下に和室向けのindigo枕を表示した。枕は頭部の左右から明確に見え、男性が枕を使って眠っていることを確認できた。枕は人物の背面に配置し、アイテムトレイ、設置アイテム、蚊、小判の視認性を阻害しない。枕アセット参照と配置スタイルは回帰テストで保護し、Vitest 20件、`pnpm check`、本番ビルドが成功した。

日本式和枕の初回生成アセットは、直接確認時に緑色の背景アーティファクトが残っていたため採用しなかった。クリーン版アセットを再生成し、ゲーム参照をクリーン版URLへ切り替えた。クリーン版の生成完了前の実画面では旧い青色の枕形が見えているため、最終確認ではクリーン版の置換後に緑色の縁・背景がないことを再確認する。

## 日本式和枕・透明背景の最終確認（2026-08-15）
