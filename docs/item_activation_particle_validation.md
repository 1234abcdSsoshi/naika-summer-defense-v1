# 共通パーティクルと発動演出：確認記録

招き猫の確認画面（`?visual-check=1&item=cat&item-hold=1&activation-check=1`）で、アイテム本体の周囲に行灯橙の発動リング、破線の木版画調印影、和紙粒子、4方向へ飛散する光粒が表示されることを確認した。

発動リングはアイテム本体より背面に表示され、招き猫のアトラス画像と右下の残り時間リングを隠さない。発動中でも効果範囲の点線リングと区別できる大きさ・明度になっている。

招き猫では行灯橙、蚊取り線香では青緑と金の共通発動リング・和紙粒子がアイテムごとの色へ追従することを確認した。いずれも防衛道具本体、射程、右下タイマーを残したまま、効果が稼働している位置を示している。

カエルでは緑、だるまでは朱の共通発動リング・和紙粒子が表示されることを確認した。カエルの口・舌の演出、だるまの巡回と小判吸引の視認性を妨げず、4種すべてで発動位置を共通ルールで示せている。

共通パーティクル素材（1920×1920、2×2セル）を直接確認した。左上は金色の和紙片と火花、右上は朱の印影片、左下は青緑の水滴・蛍光粒、右下は琥珀の護符片と光粒で構成され、すべて透明背景で合成できるゲーム用の木版画調素材になっている。

素材を決定論的に4セル（各960×960）へ切り出した。金色の和紙片・火花セルと朱の印影片セルを個別に確認済みである。アルファチャンネルの統計は、透明画素3,294,116、完全不透明画素172,970、最小アルファ0、最大アルファ255であり、緑色は透明領域に保持されたクロマ情報であってゲーム表示を覆う背景ではないことを確認した。

残り2セルも個別に確認し、左下は青緑の水滴・蛍光粒、右下は琥珀の護符片・光粒であることを確認した。4セルすべてが960×960のRGBA PNGとして切り出され、各アイテムの色調へ対応する素材が完成している。

招き猫については、射程内へ誘引した蚊がいる状態を再現し、実際の誘引効果が稼働中に `item-activation-cat is-trigger` の共通パーティクル要素が繰り返し生成されることを確認した。単なる定期点滅ではなく、射程内に誘引対象がいることを条件とする発動連動になっている。

蚊取り線香については、射程内へ蚊を配置した実効果確認で得点が増加し、直近発動属性が `incense:trigger` になることを確認した。線香の設置時演出ではなく、蚊を実際に退けた瞬間に共通パーティクルが発火している。

カエルについては、射程内へ配置した蚊の捕食後、直近発動属性が `frog:trigger` になることを確認した。舌・口開閉の既存アクションと同じ実捕食の開始に、共通パーティクルが連動している。

だるまについては、射程内へ小判を追加した実吸引確認で、直近発動属性が `daruma:trigger` になることを確認した。だるまが小判を吸引する実効果の開始に、朱色の共通パーティクルが連動している。
