# 内蚊 — イベント計測と難易度調整

## 目的と取り扱い

この実装は、プレイヤーの個人情報・端末識別子・広告識別子を送信せず、**ゲーム内行動だけ**を端末内に最大200件まで記録する。各イベントは `window` の `naika:game-event` も発火するため、将来、同意取得済みの分析基盤を導入する場合は、このイベント境界で接続できる。

| イベント | 主な属性 | 用途 |
|---|---|---|
| `run_started` | 難易度 | セッション開始数・難易度選択比率 |
| `enemy_spawned` | 敵種・段階・脅威値 | 波の密度と難易度圧の検証 |
| `tap_hit` / `enemy_defeated` | 敵種・残HP・連続数 | 命中率と敵ごとの体感難度 |
| `damage_taken` | ダメージ・残寝息 | 失敗理由と危険なスパイク |
| `coin_collected` / `item_purchased` / `item_placed` | コイン・道具・座標 | 経済圧と道具の利用率 |
| `run_ended` | 得点・時間・命中率・平均脅威 | 離脱と全体バランスの判定 |

結果画面では、当該プレイの**命中率、被弾量、平均脅威値**と、端末内に保存されたイベント件数／完走数を表示する。これはデバッグ表示を兼ね、操作の上達と難易度設計の関係をプレイヤー自身にも説明できる構成である。

## 難易度プロファイル

| プロファイル | 意図 | スポーン間隔 | 被ダメージ | 得点報酬 |
|---|---|---:|---:|---:|
| 静かな夜 | 初回の学習と情緒を優先 | 標準の約1.3倍 | 0.78倍 | 1.00倍 |
| 夏の盛り | 標準の緊張と回収の循環 | 標準 | 1.00倍 | 1.00倍 |
| 夕立のあと | 上級者向けの短い高密度体験 | 標準の約0.75倍 | 1.18倍 | 1.15倍 |

プレイ中は10秒以降、命中率と寝息に応じて**適応脅威値**を0.75〜1.25倍で調整する。寝息78以上かつ命中率66%超では少しだけ敵のテンポを上げ、寝息42未満または命中率34%未満では圧を緩める。これにより、開始時に選んだ夜の気配を尊重しながら、成功も失敗も急峻になりすぎない防衛線を維持する。

> 運用では、`run_ended` の平均脅威、命中率、被弾量、道具配置数を難易度別に比較する。命中率は高いのに短時間で寝息が尽きる場合は被ダメージか最大同時出現数を抑え、命中率が低いのに長期化する場合は当たり判定または報酬設計を見直す。
