# カエル捕食・小判自動回収の確認記録

カエルは、射程内の蚊を検知するとまず対象方向へ回転し、その側に口を移動して開く。続いて舌が口元から対象へ伸び、蚊は0.36秒かけて口元へ引き寄せられてから撃破される。これにより、口や舌が対象から離れて突然現れる挙動を解消した。

小判については、カエルの有効範囲内にあるものを0.22秒ごとに探索し、最寄りの小判を自動回収する。カエルによる蚊撃破で生成された小判も、射程内であれば同じ処理により回収される。

確認用画面では、準備段階から引き寄せ段階へ切り替わるDOM状態を確認した。引き寄せ段階では、カエルに`is-aiming`と`is-striking`、口に`is-open`が付き、舌要素と蚊が同時に存在し、対象方向を示す回転値と舌長が設定されていた。

`?visual-check=1&frog=1&item=1` の通常速度の確認では、カエル稼働中に蚊0体、得点105、小判残高5を確認した。これはカエルが蚊を撃破し、生成された小判を自動回収した結果である。Vitest 6件、型検査、本番ビルドも成功している。

さらに、蚊を出現させない小判単独確認では、小判残高が初期値4から5へ増え、得点は0のまま、画面上の小判要素は0件だった。同じDOM確認でカエルの設置要素が存在していることも確認した。これにより、撃破報酬や事前スポーンに依存せず、設置中のカエルが範囲内小判を自動回収することを確認した。
