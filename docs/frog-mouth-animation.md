# 内蚊 — カエルの口開閉アニメーション

カエルが射程内の敵を捕食する際、ゲーム本体の捕食イベントから、口の開閉状態・舌の伸長・敵の撃破を同時に開始する。通常時は小さな暗色の口を閉じ、捕食中は口の幅と高さを広げ、内側に桃色の舌が見える状態へ遷移する。舌の表示時間は約420msで、口も同じ捕食クラスに同期するため、口だけが取り残されない。

DOM表示の口は、カエルの3Dデジタル調アイコン上に重ねた小さな楕円として実装した。`transform`、`filter`、`opacity`だけを変化させ、レイアウトを動かさずに開閉の反応を出している。`prefers-reduced-motion`では既存の共通ルールによりアニメーションを短縮する。

検証用の `?demo&inspect&item&frog` 画面で、カエルの設置、20秒リング、射程範囲、敵の接近、舌捕食を確認し、`pnpm check` と `pnpm build` を完了した。
